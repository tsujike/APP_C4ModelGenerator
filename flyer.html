Quick Start Guide

Mermarium マーマリウム

アーキテクチャ図を、テキストを書くだけで作れるビューワーです。書いた内容はその場でホワイトボード風の図になり、 ズームイン/アウトするだけで「全体像」から「コードの中身」まで、詳しさのレベルが自動的に切り替わります。

Getting Started

3ステップで始められます

1
リポジトリを取得
git clone https://github.com/tsujike/APP_C4-Model-Whiteboard-Viewer.git
GitHubからダウンロードします。
2
準備する
npm install
フォルダの中で1回だけ実行してください。
3
起動する
npm run dev
表示されたURLをブラウザで開けば完了です。

How it works

左にテキストを書くと、右に図ができる

① 左側で書く「人」「システム」「つながり」を専用の書き方でテキスト入力するだけ。プログラミングの知識は不要です。
② 右側に自動描画入力内容がその場で見やすい図になります。色や形は要素の種類ごとに自動で決まります。
③ サンプルからすぐ試せる左上のメニューから組込みサンプルを読み込めば、空の状態から書き始めなくてもすぐに操作を体験できます。

The Highlight

ズームするだけで、詳しさのレベルが切り替わる

これがこのツール最大のポイントです。地図アプリで縮尺を変えると国→都市→通りと表示が変わるように、 図をズームインすると「全体の関係」から「システムの中身」「さらにコードの構成」へと、 自動的に描く内容が切り替わります。逆にズームアウトすれば、また全体像に戻ります。

→
ズームアウト ― 全体のつながりを俯瞰
ズームイン ― 中身が自動で展開される

Other Points

ここも便利なポイント

🎯
見ている場所を見失わない
気になるシステムに向かってズームインすると、その場で中身が展開されます。画面が急に切り替わって迷子になる心配がありません。
⚡
書けばすぐ反映
テキストを編集すると、約0.3秒後に図が自動で更新されます。見ている位置はそのまま保たれます。
🛟
間違えてもすぐわかる
書き方を間違えると、画面下に行番号付きでエラーが表示されます。クリックすれば該当行にジャンプできます。
💾
続きから再開できる
編集した内容はブラウザに自動保存されます。ページを閉じても、次に開いたときに続きから始められます。
🖼️
画像として書き出せる
今表示している図をSVGまたはPNG画像としてダウンロードできます。資料への貼り付けにそのまま使えます。
🌐
サーバー不要・自分のPCだけで完結
データはすべて自分のブラウザの中だけで扱われます。外部にアップロードされることはありません。
